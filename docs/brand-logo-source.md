# ALMA-STRA website logo

The transparent SVG at `public/images/brand/alma-stra.svg` uses vector paths extracted from page 7 of the client-supplied `ALMA STRA brand guideline visual identity fr.pdf`. The symbol, wordmark and tagline are arranged horizontally for the existing website header. Compound paths preserve letter counters. Colors match the rendered guide artwork. No background rectangle or raster image is embedded; no AI restoration was used.
